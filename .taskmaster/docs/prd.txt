# mimeBookmark 产品需求文档 (PRD)

## 产品概述

**mimeBookmark** 是一个现代化的浏览器书签管理工具，允许用户轻松地保存、组织和浏览他们的网页书签。

## 目标用户

- 需要管理大量书签的高级用户
- 想要快速访问常用网站的效率人士
- 需要管理多平台书签的用户（本地管理，未来支持云同步）

## 核心功能

### 1. 书签管理 (P0 - 必须)
- 添加新书签（支持URL、标题、描述）
- 编辑现有书签
- 删除书签（带确认对话框）
- 批量选择和管理

### 2. 书签展示 (P0 - 必须)
- 网格视图（卡片布局）
- 列表视图
- 缩略图预览（自动获取网站favicon）
- 响应式设计

### 3. 搜索和过滤 (P1 - 重要)
- 全文搜索（标题、描述、URL）
- 标签过滤
- 日期范围过滤
- 排序选项（最近添加、字母顺序、访问频率）

### 4. 标签系统 (P1 - 重要)
- 创建和管理标签
- 为书签分配多个标签
- 标签云视图
- 快速标签选择

### 5. 导入/导出 (P2 - 可选)
- 从浏览器导入书签
- 导出为HTML/JSON格式
- 自动备份

### 6. 用户体验 (P1 - 重要)
- 键盘快捷键
- 深色/浅色主题
- 加载状态指示器
- Toast通知系统
- 错误处理和重试机制

## 技术栈

- **框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **UI组件**: shadcn/ui
- **测试**: Playwright (E2E) + Vitest (Unit)
- **状态管理**: React Hooks
